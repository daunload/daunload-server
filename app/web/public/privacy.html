아유 하기싫어대시보드로 돌아가기

아유 하기싫어 다운로더

개인정보처리방침

시행일 · 최종 수정일: 2026년 11월 7일 · 운영자: daunload

강의 영상은 학교 CDN에서 사용자가 선택한 PC 폴더로 직접 저장됩니다. 확장프로그램은 다운로드에 필요한 영상 정보와 작업 상태를 처리합니다. 웹서비스는 로그인·권한 확인, 강의 정보 조회와 완료 이력 저장을 담당하며, 운영자는 문제 확인을 위해 이용·출석·제출 기록을 열람할 수 있습니다. 학교 비밀번호는 로그인 확인에만 쓰고 저장하지 않습니다. 운영자는 학교 로그인 세션, 알림 토큰, 전사 본문, 과제 점수를 열람하지 않습니다. 서비스는 관리자가 승인한 사용자만 쓸 수 있으며, 승인 전에는 학교 정보를 동기화하지 않습니다.

1. 적용 범위와 목적

이 방침은 daunload.cloud 웹서비스 전체와 Chrome 확장프로그램 아유 하기싫어 다운로더에 적용됩니다. 본 서비스는 학교의 공식 서비스가 아닙니다.

처리 목적은 사용자가 선택한 본인 강의의 다운로드, 대기열 관리, 진행 상황 표시, 취소, 오류 안내 및 완료 이력 제공과, 웹서비스의 운영과 문제 확인입니다. 이 과정에서 처리하는 정보를 판매하거나, 다운로드 기능과 관계없는 광고 타기팅·신용 평가·대출 판단에 이용하지 않습니다.

2. 처리하는 데이터

처리 위치·항목내용과 목적
확장 · 영상 정보선택한 강의의 영상 URL, 파일명, 영상 데이터. 해당 파일을 다운로드하고 목록에 표시하기 위해 사용합니다. 파일명이나 URL에 포함된 강의 정보도 함께 처리됩니다.
확장 · 작업 상태작업 식별자, 등록 시각, 대기·진행·완료·취소 상태, 받은 용량, 전체 용량, 오류 내용. 진행률 표시와 작업 관리를 위해 사용합니다.
확장 · 연동 정보요청을 보낸 사이트 원점, 대시보드 탭 ID, 다운로드 창 ID와 임의의 작업 세션 식별자. 창 중복 방지와 요청·상태 연결에 사용합니다.
PC · 저장 폴더사용자가 선택한 폴더의 접근 권한과 폴더명. 파일 저장에 사용하며, 확장프로그램은 폴더의 전체 경로나 기존 파일 내용을 서버에 업로드하지 않습니다. 같은 이름의 파일이 있는지 확인할 수 있습니다.
웹서비스 · 계정웹사이트는 학번, 암호화한 학교 로그인 세션(학교 통합 로그인 토큰과 LMS 세션), 이용 동의 및 로그인 기록을 처리합니다. 로그인할 때 입력한 학교 비밀번호는 학교 서버로 본인 확인을 하는 동안에만 메모리에서 사용하고 DB·로그에 저장하지 않습니다. 학교 로그인 세션은 LMS 조회와 자동 재생에 사용합니다. 로그인할 때 서버가 학교 Canvas의 액세스 토큰 기능으로 이 서비스 전용 개인 액세스 토큰(용도: “SSU LMS 자동 수강”)을 발급하거나, 사용자가 직접 발급한 토큰을 등록할 수 있습니다. 토큰은 별도로 암호화해 보관하고 학습 세션 자동 복구에만 사용합니다. 서버가 발급한 토큰이 만료·폐기되면 다음 로그인 때 새로 발급하고 이전 토큰은 폐기합니다. 개인 토큰과 학교 로그인 정보로 모두 복구하지 못하면 다시 로그인하거나 새 토큰을 등록해야 합니다. 개인 토큰은 계정 화면에서 제거하거나 계정 삭제 시 운영 DB에서 삭제됩니다. 학교 Canvas는 토큰 자체의 폐기를 비밀번호 로그인 화면에서만 허용하므로, 이때 Canvas의 토큰은 남아 있습니다. 서버가 발급한 토큰과 직접 발급한 토큰 모두 Canvas 설정의 “승인된 통합”에서 언제든 직접 폐기할 수 있습니다. 확장프로그램에 학교 비밀번호·로그인 쿠키를 전달하지 않습니다. 승인 전에는 로그인할 수 있어도 학교 정보를 동기화하지 않으며, 승인 후에 동기화합니다. 주기 동기화는 승인된 사용자의 자동 재생 과목에 한해 2시간 간격으로 실행합니다. 전체 동기화는 처음 로그인하거나 만료 후 다시 로그인할 때, 동기화 버튼, 승인 때 실행합니다.
웹서비스 · 이용 권한관리자의 승인을 받은 사용자만 서비스를 쓸 수 있습니다. 권한 요청 시각, 결정 시각, 결정한 관리자의 학번, 거절 횟수와 직전 권한 상태를 기록합니다. 권한 확인과 요청 처리, 재요청 제한(거절 후 24시간)을 위해 사용하며, 운영자는 승인·거절·권한 회수를 위해 이를 열람합니다. 사용자가 권한을 요청하면 학번이 담긴 알림("학번 ○○ 님이 승인을 요청")이 관리자가 설정한 Discord 알림 채널로 전송됩니다.
웹서비스 · 강의·이력본인 과목·강의 정보, 저장된 영상 주소와 다운로드 이력(항목, 제목, 횟수, 시각)을 처리합니다. 영상 접근 확인과 받은 항목 표시를 위해 사용합니다. 완료 이력은 클라이언트의 보고를 기준으로 합니다.
웹서비스 · 일별 이용 기록하루 단위의 로그인 횟수와 다운로드 횟수를 계정별로 기록합니다. 서비스 운영과 이용 문제 확인을 위해 사용합니다.
웹서비스 · 재생·출석·제출 기록강의 재생 기록, 출석 정보, 과제 제출 상태를 처리합니다. 운영자는 문제 확인을 위해 이 기록을 열람할 수 있습니다. 또한 학교 LMS 연동과 영상 주소 확인에 오류가 발생한 시각을 기록합니다.
접속·운영 정보네트워크 요청 과정에서 IP 주소, 요청 주소, 시각, 응답 상태 등 접속 정보가 서버나 학교/CDN에 남을 수 있습니다. 서비스 제공, 접속 제한, 장애 확인과 보안을 위해 처리합니다.

운영자 열람: 운영자는 서비스 운영과 문제 확인을 위해 사용자의 권한 요청·결정 기록, 이용 횟수, 재생·출석·제출 기록을 읽기 전용으로 볼 수 있습니다. 학교 로그인 세션, 알림 토큰, 전사 본문, 과제 점수는 열람하지 않습니다. 학교 비밀번호는 저장하지 않으므로 열람할 수 없습니다.

확장프로그램은 전체 웹 방문 기록, 일반적인 키 입력·마우스 움직임, 결제·건강·개인 메시지·GPS 정보를 수집하는 기능을 제공하지 않습니다. 선택한 영상의 URL과 다운로드 동작에 관한 정보는 위 목적에 필요한 범위에서 처리합니다.

3. 데이터 전송과 외부 서비스

  • 영상 파일: 학교 또는 강의 CDN에서 사용자 PC로 전송됩니다. 확장 다운로드 경로에서는 영상 파일을 daunload.cloud 서버에 중계·저장하지 않습니다. 네트워크 연결 상대인 학교/CDN은 사용자 IP와 요청 정보를 확인할 수 있습니다.
  • 텍스트 변환용 소리: 텍스트 변환을 쓰면 확장프로그램이 학교 CDN에서 강의 영상을 읽어 브라우저 안에서 소리만 뽑아 연동 웹사이트에 넘깁니다. 영상과 소리는 서버로 보내지 않으며, 변환 결과 텍스트만 서버에 저장됩니다.
  • 다운로드 상태: 확장프로그램이 대기·진행·완료 상태를 대시보드에 전달합니다. 대시보드는 로그인된 사용자의 다운로드 완료 정보를 웹서비스 서버에 보고합니다.
  • 승인 요청 알림: 사용자가 사용 권한을 요청하면 요청한 사용자의 학번이 포함된 알림이 관리자가 설정한 Discord 채널로 전송됩니다. 이 알림은 사용자가 설정하는 알림과 별개이며, 학번 외의 정보는 담지 않습니다. Discord는 외부 서비스로, 해당 서비스의 방침에 따라 메시지가 처리됩니다.
  • 학교 로그인: 웹사이트의 계정 연결과 권한 조회 과정에서 학교 인증·LMS 서버와 통신합니다. 이 로그인 과정은 확장프로그램의 영상 전송과 구분됩니다.
  • 확장 실행 코드: 코드와 화면 리소스는 확장 패키지에 포함됩니다. 확장이 외부 JavaScript나 WebAssembly를 다운로드해 실행하지 않습니다.

연동 웹사이트의 다른 기능은 추가적인 외부 요청을 할 수 있습니다. 예를 들어 대시보드는 외부 글꼴·광고 리소스를 불러오며, 텍스트 변환을 사용하면 브라우저에서 외부 모델 파일을 받습니다. 알림 기능을 설정하면 선택한 Discord·Telegram 등으로 알림 내용이 전송됩니다. 해당 기능은 확장 다운로드 기능에 필수인 것은 아닙니다. 이 개인정보처리방침 페이지는 광고·분석 스크립트나 외부 글꼴을 로드하지 않습니다.

4. 보관 기간과 삭제

  • 확장 임시 정보: 작업 정보는 chrome.storage.session에 임시 보관합니다. 브라우저 종료나 확장 재로드·업데이트·비활성화 등으로 세션 저장소가 초기화될 때 삭제됩니다. 브라우저를 오래 켜 둔 경우 새 작업 등록 시 7일이 지난 종료 작업을 정리합니다.
  • 폴더 접근: 선택한 폴더의 핸들은 다운로드 창의 메모리에서 사용하며 서버에 저장하지 않습니다. 다운로드 창을 닫거나 새로고침하면 다시 폴더를 선택해야 할 수 있습니다.
  • 다운로드 파일: 저장된 영상은 사용자 PC에 남습니다. 확장 제거·계정 삭제로 자동 삭제되지 않으며 사용자가 직접 지울 수 있습니다. 중단된 작업은 확장이 새로 만든 미완료 파일의 정리를 시도합니다.
  • 웹 계정·다운로드 이력: 서비스 제공을 위해 계정 이용 기간 동안 보관하며, 웹사이트 계정 메뉴의 계정 삭제 시 운영 DB의 계정·자격증명·연동 데이터와 함께 삭제합니다.
  • 권한 요청·결정 기록: 계정 이용 기간 동안 보관하며, 계정 삭제 시 함께 삭제합니다. 권한이 회수되거나 거절되어도 기록은 삭제하지 않고 유지합니다. 권한이 회수된 사용자는 다시 요청할 수 있고, 거절된 사용자는 결정 24시간 뒤에 다시 요청할 수 있습니다.
  • 일별 이용 기록: 일별 로그인·다운로드 횟수는 90일간 보관한 뒤 삭제하며, 계정 삭제 시 함께 삭제합니다.
  • 백업·접속 로그: 계정 삭제가 이미 생성된 운영 백업과 접속 로그를 즉시 삭제하지는 않습니다. 현재 배포의 로컬 백업은 정기 백업 실행 시 14일이 지난 파일을 정리하고, 컨테이너 로그는 용량 제한에 따라 순환합니다. 구체적인 삭제 요청은 아래 문의처로 연락할 수 있습니다.

5. 권한과 보호 조치

  • storage: 작업 상태와 다운로드 창 식별자의 임시 보관에 사용합니다.
  • declarativeNetRequest: 확장이 시작한 학교·CDN 요청의 Referer·Origin 헤더 설정 및 허용 도메인 밖 요청 차단에 사용합니다. 일반 웹 탐색 요청을 변경하지 않습니다.
  • 학교·CDN 호스트 접근: 선택한 영상 파일을 직접 가져오는 데 사용합니다. 대시보드 콘텐츠 스크립트는 https://daunload.cloud/*에서 다운로드 연동을 수행합니다.

영상 주소는 허용된 학교·CDN의 HTTPS 주소로 제한하고 파일명과 메시지 발신자를 검사합니다. 웹서비스는 학교 비밀번호를 저장하지 않고 학교 로그인 세션과 개인 액세스 토큰(서버 발급 또는 사용자 등록)을 암호화해 보관합니다. 서비스 로그인은 매번 학교 통합 로그인으로 확인합니다. 로그인 요청은 서비스 서버를 거쳐 학교로 전달되므로, 서버 운영자가 이를 저장하지 않는다는 점은 운영 정책으로 보장합니다.

6. 이용자의 선택과 권리

사용자는 다운로드를 취소하고 폴더 선택을 거부할 수 있으며, Chrome에서 확장을 비활성화하거나 제거할 수 있습니다. 웹사이트의 계정 삭제 기능으로 계정과 연동 데이터 삭제를 요청할 수 있습니다. 열람·정정·삭제 또는 처리 중단에 관한 요청과 질문은 아래 이메일로 접수합니다. 계정 관련 요청은 본인 확인 후 처리합니다. 문의 시 학교 비밀번호나 로그인 토큰을 보내지 마세요.
