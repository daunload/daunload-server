강의는 받아 두고, 복습은 내 시간에.

아유 하기싫어 다운로더는 daunload.cloud에서 선택한 숭실대학교 강의 영상을 내 PC의 폴더에 직접 저장하는 Chrome 확장프로그램입니다. 개별 영상은 물론 여러 강의를 한 번에 등록하고, 별도의 다운로드 창에서 저장 과정을 확인할 수 있습니다.

왜 설치해야 하나요?
웹사이트에서 고른 강의를 내 컴퓨터의 저장 기능과 연결해 줍니다. 사용자가 폴더를 선택하면 확장프로그램이 학교 CDN에서 영상을 직접 받아 저장하므로, 별도의 PC용 다운로드 프로그램을 설치하거나 영상 주소를 일일이 복사할 필요가 없습니다. 받아 둔 강의는 개인 복습에 활용할 수 있습니다.

주요 기능
• 개별 받기와 전체 받기: 선택한 강의를 다운로드 목록에 등록합니다.
• 순서대로 저장: 전체 목록을 보여 주고, 실제 저장은 최대 2개씩 진행합니다. 나머지 영상은 대기 상태로 표시됩니다.
• 저장 폴더 선택: 원하는 폴더에 영상을 모아 저장합니다.
• 진행 상황 확인: 영상별 진행률, 받은 용량, 대기·저장 중·완료 상태를 확인합니다.
• 다운로드 취소: 진행 중이거나 대기 중인 항목을 취소할 수 있습니다.
• 같은 이름의 파일 보호: 파일명이 겹치면 번호를 붙여 기존 파일을 덮어쓰지 않습니다.
• 독립된 다운로드 창: 대시보드를 그대로 두고 별도 팝업 창에서 작업합니다. 확장 아이콘으로 창을 다시 불러올 수 있습니다.

이용 방법
1. 데스크톱 Chrome에 확장프로그램을 설치합니다.
2. https://daunload.cloud/ 에서 로그인하고 내려받을 강의를 선택합니다.
3. 내려받기 또는 전체 받기를 누릅니다.
4. 열린 다운로드 창에서 저장 폴더를 선택합니다.
5. 저장 완료를 확인합니다.

이용 전 확인해 주세요
• daunload.cloud 계정과 본인 강의에 대한 접근 권한이 필요합니다.
• Chrome 120 이상에서 사용할 수 있습니다.
• 다운로드 창을 닫으면 진행 중인 저장이 중단됩니다. 완료 이력 기록을 위해 대시보드도 열어 두세요.
• 자동 이어받기는 지원하지 않습니다. 중단된 영상은 다시 내려받아야 합니다.
• 학교가 영상을 삭제하거나 제공 주소를 변경하면 다운로드가 제한될 수 있습니다.
• 내려받은 자료는 이용 권한 범위 안에서 개인 학습용으로 사용해 주세요.

이 확장프로그램은 학교 공식 서비스가 아닙니다.
